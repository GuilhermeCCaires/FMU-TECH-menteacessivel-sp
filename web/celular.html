Abra o app no seu celular Android

Criando o link...

1. Escaneie o QR code

  1. Abra a câmera do celular (ou o Google Lens) e aponte para o QR code.
  2. Toque no link que aparecer.
  3. Se der erro, espere 20 segundos e recarregue: o link leva um tempinho para ativar.

Ou envie o link para você mesmo:

Enviar pelo WhatsApp

2. Instale como aplicativo

No Chrome do Android, toque no menu ⋮ e depois em Instalar app (ou Adicionar à tela inicial). O MenteAcessível ganha um ícone como qualquer aplicativo.

Alternativa: mesma rede Wi-Fi

Com o celular na mesma Wi-Fi do computador, tente um destes endereços. O GPS não funciona por eles (não são https); digite o CEP ou a cidade.

    O link funciona enquanto o computador estiver ligado e o terminal com python -m app.celular aberto. Ele muda a cada vez e qualquer pessoa com o link consegue abrir: use para testes.
